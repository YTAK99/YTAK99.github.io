ABOUT ME · 02

기능 구현을 넘어, 서비스 전체의 흐름을 연결합니다.

아이디어를 화면으로 옮기고, 데이터를 설계하고, 서버에 배포해 다른 사람이 사용할 수 있게 만드는 과정 전체를 좋아합니다.

전자공학에서 하드웨어와 네트워크의 동작 원리를 익혔고, 보안 학습을 통해 시스템을 세밀하게 관찰하는 습관을 길렀습니다. 이후 웹 개발로 영역을 넓혀 두 번의 팀 프로젝트에서 기획, 프론트엔드, 백엔드, 인프라를 두루 경험했습니다.

새로운 기술은 구조와 제약 조건을 먼저 확인한 뒤 적용합니다. 구현한 결과는 빌드와 테스트, 실제 접속을 통해 검증하며 끝까지 동작하는 결과물로 완성합니다.

AI를 활용하되, 판단과 검증은 직접.

    맥락부터 확인

    작업을 나누고 변경 범위를 좁혀 원인을 추적할 수 있게 만듭니다.

    동작으로 검증

    빌드, 테스트, 로그와 실제 화면을 통해 생성 결과를 확인합니다.

    운영 정보는 분리
