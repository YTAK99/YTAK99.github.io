HOW I WORK · 05

AI를 활용하되, 판단과 검증은 직접.

빠르게 생성하는 것보다 현재 프로젝트의 구조를 이해하고, 결과를 검증할 수 있는 방식으로 AI를 활용합니다.

  1. 01

    맥락부터 확인

    현재 코드, API 계약, 버전과 제약 조건을 먼저 확인합니다.

  2. 02

    작은 단위로 구현

    작업을 나누고 변경 범위를 좁혀 원인을 추적할 수 있게 만듭니다.

  3. 03

    동작으로 검증

    빌드, 테스트, 로그와 실제 화면을 통해 생성 결과를 확인합니다.

  4. 04

    운영 정보는 분리

    비밀값과 운영 설정을 코드에서 분리하고 공개 범위를 관리합니다.
